# BUConnect

BUConnect is a college placement and student query management platform.

## Features

- View placement companies
- Filter companies according to eligible branches
- Student Query Board
- Duplicate query detection
- Query priority system
- Students can support an existing query using the + button
- Students and admins can reply to queries
- Query status: Pending, In Progress and Resolved
- Admin and query raiser can resolve a query
- Affected students can report "Still Facing Issue"
- Admin can manage and delete queries

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
